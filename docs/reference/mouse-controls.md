# Mouse Controls

A reference for mouse interactions in the main areas of Subtitle Edit.

See also: [Audio Visualizer](../features/audio-visualizer.md) | [Video Player](../features/video-player.md)

## Video Player

| Action | Effect |
|--------|--------|
| Click on video | Play/Pause toggle |
| Scroll wheel over video | Seek ±0.5 s per notch (direction follows the waveform's "Invert mouse-wheel" setting) |

Full screen is toggled with Alt+Enter — see [Keyboard Shortcuts](keyboard-shortcuts.md).

## Audio Visualizer / Waveform

| Action | Effect |
|--------|--------|
| Left-click | Set current position |
| Left-click + drag on subtitle edge | Adjust start/end time of subtitle |
| Left-click + drag in empty area | Create a new selection |
| Shift + Click | Set the selected subtitle's start time to the clicked position |
| Ctrl (or Cmd) + Click | Set the selected subtitle's end time to the clicked position |
| Ctrl + Shift + Click | Set the selected subtitle's start time and offset all following subtitles by the same amount |
| Alt + Click | Move the selected subtitle's start to the clicked position, keeping its duration |
| Right-click | Select the subtitle under the cursor ("Select subtitle on right click", on by default), move the video position there, and open the context menu. On macOS, Ctrl + left-click opens the same menu |
| Scroll wheel | Scroll waveform horizontally — or seek the video by one step per notch when "Mouse-wheel sets video position" is on; "Invert mouse-wheel" flips the direction (Options → Settings → Waveform/spectrogram) |
| Alt + Scroll wheel | Horizontal zoom in/out |
| Shift + Scroll wheel | Vertical zoom in/out |
| Ctrl (or Cmd) + Scroll wheel | Scroll waveform and seek video to cursor |
| Double-click | Nothing by default — set "Waveform double-click action" in Options → Settings → Waveform/spectrogram to select the subtitle, center on it, pause, or play |

## Subtitle Grid

| Action | Effect |
|--------|--------|
| Click on row | Select subtitle line |
| Double-click on row | Go to the subtitle in the video and pause (default; "Subtitle grid double-click action" in Options → Settings → General offers other actions, e.g. play, or also focus the text box) |
| Ctrl + Click | Toggle selection of individual rows |
| Shift + Click | Select range of rows |
| Right-click | Open context menu |

## General

| Action | Effect |
|--------|--------|
| Drag and drop file | Open the dropped subtitle or video file |
